GreenTrail

Community hiking trails — maps, events, and trail tips

Naming Conventions

All files and folders follow course naming conventions and are included in this project folder. Example: project/siteplan.html, project/css/styles.css, project/js/main.js, project/images/logo.svg.

HTML Validation

This document uses semantic HTML and follows W3C validator rules. The document has been written to avoid common validation errors (proper doctype, lang, required meta charset, alt text for images, etc.).

CSS Validation

Styles are in css/styles.css and follow W3C CSS validator best practices.

Site Name

Site name: GreenTrail

Reason: The name emphasizes ecological, outdoor trail experiences and community — it is short, brandable, and descriptive of the project's focus on hiking trails and nature.

Site Purpose

  • Provide curated trail maps and difficulty ratings for local hiking routes.
  • Share event listings (guided walks, cleanups) and allow users to sign up for membership/newsletters.
  • Offer trail guides, safety tips, and gear recommendations.

Scenarios

  1. New hiker: "Which trails are beginner-friendly and dog-friendly within 20 km of my location?"
  2. Event attendee: "How do I register for the next guided night hike and where is the meeting point?"

Color Schema

At least two colors are defined and used in this document:

  • Primary (Forest Green): #0b7a4a — used for headings, primary buttons, and accents.
  • Accent (Sun Apricot): #f08a5d — used for call-to-action highlights and links.
  • Neutral (Background): #f7f8fa — page background; and text color #222222.

The colors above are actively used in the stylesheet below to style headings, buttons, and backgrounds.

Typography

  • Heading font: Merriweather (serif) — used for all major headings (h1, h2).
  • Body font: Roboto (sans-serif) — used for paragraphs, lists, and UI text.

The fonts are loaded from Google Fonts and used site-wide via the stylesheet.
